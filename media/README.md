# Experiment feed

Place the recorded run here as `experiment.mp4`.

The application works without it — the feed panel shows a placeholder and the
procedure runs on an internal clock — but the demo is far more convincing with
real footage, because the video's playback position drives the scenario and
therefore every observed action.

Record it with:

    ./tools/record_demo.sh 0 85

Cue timings are documented in that script and must match
`scenarios/demo_master.json`.
